# [Frontseat](https://www.frontseat.dev)

**Build orchestrator for the agentic era.**

Agents write code at machine speed. Your builds should keep up. Frontseat gives every agent and developer the freedom to build, test and experiment at full speed, without slowing each other down.

- **Build less. Move faster.** Frontseat builds only what changed and shares results across your team. No duplicated work, no stale results. Just fast, correct builds that get smarter with every run.

- **Your tools. Supercharged.** Keep your existing compilers, linters and test runners. Frontseat works with the project files you already have. No new build language, no migrations, no rewrites.

- **One agent or a hundred.** Give every agent its own isolated workspace for any repository or branch. Run locally, in containers or virtual machines, with the same seamless experience everywhere. Everyone builds, tests and experiments independently, without getting in each other's way.

- **Let agents loose. Not your secrets.** Every build runs in an isolated sandbox with access only to what it needs. Agents can experiment freely while your machines and credentials stay safely out of reach.

- **Many repos. One connected world.** Frontseat uses your developer portal's software catalog, with [Backstage](https://backstage.io/) as the default format, to connect dependencies across repositories. Get monorepo ergonomics without the monorepo, while every team keeps its own code and ownership.

- **Bring your infrastructure along.** Frontseat speaks Bazel's Remote Execution API (REAPI), giving you the freedom to run your own build infrastructure or use managed services like [BuildBuddy](https://www.buildbuddy.io/) and [EngFlow](https://www.engflow.com/). Your builds, your infrastructure, your choice.
