# Mistakes made in server/

The mistakes made in the server module (the daemon and its engine, the
source a daemon holds, the control plane, the sandbox service and its
drivers, the runner, the confiner, the shared packages and the test
support), each with the check that stops it. The rules every change
keeps are in the root `AGENTS.md`. Run the check; do not trust that you
would not make the mistake.

## Servers, sandboxes and the control plane

| The mistake | The check |
|---|---|
| A workspace's sandbox was let through to a forge for a publisher no box ships, kept after publishing moved to actions; a release from a workspace then tagged, pushed and failed to publish, and making it again did not finish it. | What a workspace cannot serve is refused by name before anything is built or tagged (`TestAReleaseFromAWorkspaceThatWouldPublishIsRefusedBeforeItBuilds`); a rule that names a program is written with a spec that runs that program through it. |
| A test of one feature imported another feature's test support or a server driver, and passed while the architecture test failed. | Cross-feature setup goes through the public API or the SDK; run `go test -race ./specs/architecture/` before a long runtime proof, and add no import exception for a test. |
| A server released what its handlers use after joining only its accept loop, or after closing connections without joining their handlers. | Close admission, cancel request contexts, then join every admitted handler, hijacked requests and SSH sessions included; test a blocked cleanup, an unfinished handshake and a running command. |
| Repeated port-zero reverse forwards leaked listeners, and one editor's disconnect could close another's reused port. | Test cancellation, disconnect and shutdown with one and with several forwards, and a released port reused on another connection. |
| A private type leaked through a public signature behind an alias or an inferred value. | `TestPublicSignatureControlsFollowAliasesAndValues` follows reachable declarations, with direct, aliased, inferred and allowed controls. |
| The servers gave reasons no contract named, and refused what they do not serve three ways (`RELEASE_UNSERVED`, `SPEC_UNSERVED` as a failed precondition, `CAPABILITY_UNSUPPORTED` as one); the control plane read a driver's lack of a capability by the code it was then refused with. Found by review. | A reason is a literal or a constant where it is given, and the contract of its domain names it (`TestEveryReasonAServerGivesIsNamedInItsContract`); what is not served is `UNIMPLEMENTED` with `<WHAT>_NOT_SERVED` (`refusedAsNotServed` in `controlplane_test.go`); a caller of another service acts on its reason or on a code its contract gives, read in the contract first. |
| A driver passed its conformance without doing the thing: a "reached" port was closed, a stream handed back unopened. | A suite holds a driver to what a caller relies on (a reached port is written to and answered, `drivertest.Conforms`), and a new driver runs under the real specs before its conformance is believed. |
| A value of several lines (indented JSON, an SSH key with its line's end) told through a sandbox's environment was taken by one runtime and refused by another. | What a sandbox is told is one argument a value (`local.Grid.Arguments`) and one line where it is a variable; a driver's conformance sandbox carries what a real one does. |
| A service given credentials answered anyone: OpenShell's gateway took a call with no credential as an administrator's. | Before a service is given a secret, read from its source who it answers; have it know its callers by a certificate, and prove one without it refused beside one with it (`TestTheGatewayAnswersNoOneWithoutItsCertificate`). |
| The control plane served the sandbox API and every sandbox's ports on its endpoint and checked no caller. | The endpoint answers its owner's token alone (`TestACallWithoutTheOwnersTokenIsRefused`), serves no sandbox call (`TestNoSandboxCallIsServedOnTheEndpoint`, `TestTheStacksEndpointRunsNothingInASandbox`), leads `/workspaces/{name}/build/` to the build API alone (`TestTheBuildRouteLeadsToTheBuildServicesAlone`), and ends only the sandboxes it asked for (`TestASandboxAnotherLabelledForAWorkspaceIsNotEndedWithIt`); a test reaches the sandbox service through `controlplanetest`. |
| A credential was kept one per host for the whole server, so one person's token fetched and pushed for another's workspace. | A credential is its owner's, kept by owner and host (`credentialID`), attached only to a rule for that host (`TestOnePersonsCredentialIsNotUsedByAnothersWorkspace`, `TestAPersonsCredentialsAreTheirsAlone`), and a workspace is its owner's (`TestAWorkspaceIsItsOwners`). |
| A record kept where another reader takes it for its own (`credentials.json` among the workspaces') stopped the control plane from starting again, and a token was led elsewhere by a redirect. | Keep a record where no other reader looks (`TestAControlPlaneThatKeepsACredentialStartsAgain`); present a token to its origin alone and follow no redirect with it (`TestATokenIsNotLedElsewhereByARedirect`, `TestARedirectFromABoxIsNotSaidOn`). |
| The daemon resolved entities through catalogs each request named, fetched with Go's default client (redirects followed, no size limit), and the sandbox was opened to their hosts. | Entities are resolved on the control plane, through the one Backstage its operator gives it, by one client held to its origin (`server/internal/backstage`: `TestARedirectIsNotFollowed`, `TestAnAnswerOfMoreThanItsLimitIsRefused`, `TestACatalogIsDialledOnlyWhereItMayBe`, `TestTheTokenIsPresentedToTheCatalogAlone`); a sandbox reaches the repositories resolved and not the catalog (`TestAnEntityResolvesToTheRepositoriesItsSandboxReachesAlone`); without one, entities are refused by name (`TestAWorkspaceOfEntitiesIsRefusedWhereNoneAreServed`). |
| A relay closed both directions when one copy reached its end, losing a request sent after the server had answered. | Close each write half on its own and join both copies; try a server that half-closes first, directly and through the relay (`TestAServiceRouteCarriesARequestSentAfterTheServerHalfClosed`). |
| Cleanup registered only what a successful creation returned, so a sandbox whose creation reply was lost was left behind. | Register ownership and cleanup before creating, and reconcile the owner's records after; lose a real creation reply and see its sandbox removed (`TestASandboxWhoseCreationReplyWasLostIsCleanedUp`, `TestAnAttemptReconcilesARealCreationWhoseReplyWasLost`). |
| A repeated creation request was taken for a fence, and a delayed original arrived after cleanup and made another sandbox. | Admit creations on a private server, and close and join admission before listing and deleting (`TestAnOriginalCreateDeliveredAfterCleanupCannotRecreate`, `TestCleanupJoinsAnAlreadyAdmittedCreation`); a cleanup endpoint is bound before the original closes (`TestFrontseatComparisonRefusesACreationDeliveredAfterCleanupBegan`, `TestFrontseatComparisonReleasesASandboxWhoseCreationReplyWasLost`). |
| Restart cleanup went on past a failed consumer deletion, released its provider and admitted new work. | Stop at the first failure, keep reverse dependency order across retries, and remove attempt files only after the sandboxes are gone (`TestRestartCleanupKeepsDependenciesOfAnUndeletedConsumer`). |
| A benchmark asked for a workspace's deletion and closed its control plane before the deletion ended, leaving a sandbox running. | Register one cleanup before creating, wait until `WaitWorkspace` ends with `NOT_FOUND`, and see the gateway empty after the test (`TestFrontseatComparisonReleasesItsSandboxWhenTheTestEnds`). |
| A PostgreSQL allocation was created open and restricted afterwards, so an existing consumer connected meanwhile and kept its session. | Create with `ALLOW_CONNECTIONS false`, grant, then enable; try a consumer's connection between the steps (`TestAPostgresAllocationIsClosedWhileItsGrantsArePrepared`). |
| A test read the absence of credentials from the sandbox it asked for, although the runtime and image can add variables. | Check the running process's variables, without printing their values, beside a control the same check refuses (`TestAnApplicationServiceIsNotReadyWithAnInvalidDependency`). |
| A probe's grid fixture copied the probe alone after the probe began importing a shared library. | Give the fixture the library's real source at its real path, and run the workspace build too (`TestABuiltApplicationServiceHasPrivateDependencies`, `TestAPinnedToolServiceCanDependOnABuiltApplication`). |
| A driver said "not found" of a sandbox its provider was still deleting, and the workspace was said to be gone. | "Not found" is said only of what the provider holds no more, and an ending sandbox is listed as ending (`driver.Ending`); test a lingering ending with a provider that holds on (`drivertest.Memory.Linger`, `drivertest.Lingering`; `TestASandboxWhoseEndingLingersIsStillListed`, `TestAWorkspaceIsNotGoneWhileItsSandboxIsStillEnding`) beside one that ends by itself (`TestASandboxThatEndedByItselfIsForgottenAndItsRequestMakesAnother`). |
| Driver tests named sandboxes and containers by fixed names, and two checkouts' runs ended each other's. | A test's sandbox has an id of its own (`testrun.ID`) and a run label (`testrun.Label`); one already held under an id is refused, never ended (`TestRunningEndsNoSandboxItDidNotMake`); a run's leftovers are listed by `FRONTSEAT_TEST_LEFTOVERS=list mise run go:test -- -v -run TestTheSandboxesARunLeftAreListedWhenAsked ./server/sandbox/driver/openshell/`, and nothing deletes another's by a pattern. Run such a suite in two processes at once before trusting it on a shared provider; find a sandbox by the gateway's id of it (`containersOf`), never by a name; end one run's leftovers at the gateway with `FRONTSEAT_TEST_LEFTOVERS=<run>` once its process is gone, and the container driver's by `docker ps --all --filter label=frontseat.dev/test-run` and `docker rm --force` of each and of its `dev.frontseat.sandbox.of=<name>` containers. |
| The control plane served records of workspaces of no owner to every caller, kept for records written before workspaces had owners. | A record this server did not write, of no owner or generation, stops it starting and names its file (`TestARecordOfNoOnesWorkspaceIsRefusedWhenTheControlPlaneStarts`); no compatibility is kept until Frontseat is public. |
| The sandbox service, called in the control plane's process, kept and answered the caller's own spec, so each changed what the other held. | The service clones a spec on the way in and out (`TestASpecAskedOrAnsweredIsNotTheServicesOwn`). |
| A driver of the container runtime, which no program used, was kept among the servers' packages, with a rule of the architecture test to carve it out. | What only tests use is test support (`server/testsupport/testcontainer`); no program makes a sandbox with it (`TestNoProgramMakesSandboxesWithTheContainerRuntime`). |
| A host, a path, a program and a secret were read by a reader of each layer's own, the control plane's and the gateway's driver's apart, and a record was kept by a store of each kind's own, one of them not written whole. | Read a name from outside with `server/internal/plain` (`Ruled`, `OriginOf`, `Path`, `Program`, `Parameter`, `Secret`; `TestAnOriginIsReadAsARuleNamesIt`) and keep a record with `server/internal/records` (`TestARecordKeptIsReadBackListedAndDropped`). |
| A repository's address was read three ways: the control plane kept one with a query that the daemon then refused, wrote no rule for one the daemon converts to https, and took a host written as a number that the gateway's driver refused later. | The control plane reads a remote as the daemon will, through the version control system's port (`vcs.Fetching.Cloned`), then as an address (`fetched`), when the workspace is asked for, and refuses what is none before anything is kept (`TestARepositorysAddressIsReadOnceAsTheDaemonReadsIt`, `TestWhereASandboxClonesARemoteFrom`). |
| A workspace's repositories were brought on a context of no one's, with no bound: a forge that accepted and never answered left the workspace being populated for ever, which refuses every later source, and nothing could stop the clone. | What brings a repository runs under the workspace's own context, each within a bound that its failure says, and `Workspace.Close` stops and joins it (`TestARepositoryNotBroughtWithinItsBoundFailsTheWorkspaceWhichSaysSo`, `TestClosingAWorkspaceStopsWhatIsBringingItsRepositories`), and the daemon closes its workspace when it closes (`TestClosingADaemonEndsWhatIsBringingItsWorkspacesRepositories`). |
| A clone stopped midway by a daemon that ended left its directory, and every later source was refused the place for good. | A clone says itself unfinished beneath `.frontseat` until its repository is recorded, and opening the workspace removes what an unfinished one left (`populate.Settle`), never a directory no clone made (`TestAWorkspaceOpenedAgainOverACloneStoppedMidwayBringsIt`). |
| Tests that make sandboxes at the real gateway ran in `mise run check`. | Such a test is asked for by a flag (`-cleanup`) that `mise run test` gives; run the package without it and see each skip. |
