# Mistakes made in the server programs

The mistakes made in what the server programs are made of, which is
`build/`, `workspace/`, `sandbox/`, `grid/`, `common/`, `core/`,
`testsupport/` and `cmd/` (the daemon and its engine, the
source a supervisor holds, the control plane, the sandbox service and its
drivers, the runner, the confiner, the shared packages and the test
support), each with the check that stops it. The rules every change
keeps are in the root `AGENTS.md`. Run the check; do not trust that you
would not make the mistake.
